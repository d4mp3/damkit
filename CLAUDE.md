# devkit (Claude Code plugin)

This repo is both a Claude Code plugin (`devkit`) and its marketplace (`dampe`).
Human docs are in Polish (README, docs/), model-facing files in English (ADR-0005).

## Commands
- Validate manifests: `claude plugin validate .`
- Guard hook tests: `python3 hooks/test_guard_readonly.py`
- Try the plugin without installing: `claude --plugin-dir .` (from any project dir: `--plugin-dir ~/dev/devkit`)
- Refresh an installed copy: `claude plugin marketplace update dampe`

## Conventions
- Agents are stack-agnostic roles; technology knowledge goes into skills (ADR-0002).
  Don't add "<tech>-expert" agents.
- Skill `description` = when to use it (triggers, symptoms), never a summary of the workflow.
  Keep SKILL.md focused (≲150 lines) and move heavy reference into `references/`.
- Preload skills into agents by bare name (`skills: [review-standards]`), which is verified to work.
  Reference other plugin files as `${CLAUDE_PLUGIN_ROOT}/...`.
- Plugin agents ignore `permissionMode`/`hooks`/`mcpServers`. A new read-only agent gets
  `disallowedTools: Edit, Write, NotebookEdit`, an entry in `READONLY_AGENTS` in
  `hooks/guard_readonly.py`, and a test case (ADR-0003).
- Set `effort` explicitly on agents whose quality must not depend on the session's effort level
  (reviewers, investigators). Omit it only when inheriting is the point (ADR-0008).
- Bump `version` in `.claude-plugin/plugin.json` on every behavior change.
- Files to be copied into projects live in `skills/<name>/assets/`. Add one only when a concrete
  file carries decisions better than prose and cannot be generated by a scaffolder (ADR-0010).
  Don't add per-language agents or config templates.
- Documentation follows `skills/documenting-code`. Record decisions as ADRs in `docs/adr/`, and
  when adding one, add a row to the ADR table in README.md.
- `_archive/` holds the old v1 agents. They are not loaded; don't edit them.
- `codex/` is an independent Codex variant (ADR-0011). When changing `skills/`, `agents/` or `hooks/`,
  consider porting the change there and run `python3 codex/scripts/check.py`.
